Kathmandu Rain Prediction
I built a Kathmandu rain prediction project using Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn and Streamlit.
I cleaned and transformed a 10-year Kathmandu weather dataset with 3,468 records and 14 meteorological variables, including unit conversion and feature engineering.
I compared four classification models, Logistic Regression, Decision Tree, K-Nearest Neighbors and Random Forest, using stratified cross-validation.
I selected Random Forest as the final model, achieving 84% accuracy and 0.90 ROC-AUC on held-out test data.
Feature importance analysis identified humidity, temperature and cloud cover as the strongest rainfall predictors, which matches real Kathmandu Valley monsoon patterns.
I applied bootstrap resampling to estimate monthly rain probabilities with lower and upper uncertainty bounds.
I developed a SARIMA seasonal time-series model to forecast the monthly percentage of rainy days.
I deployed the trained model as an interactive Streamlit web application that classifies rain in real time from user-defined weather inputs.

Chini, a Diabetes Risk Predictor for Women
I built Chini, a diabetes risk predictor for adult women, using Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SciPy, Streamlit and Docker.
I built the diabetes risk predictor on the Pima Indians dataset with 768 records, using a Scikit-learn pipeline that fills in missing values and scales features, so it works even with incomplete patient data.
I used Welch's t-test and Cohen's d to find which measurements best separate diabetic and non-diabetic patients.
I compared five models with 5-fold cross-validation and tuned each with GridSearchCV, including L1, L2 and ElasticNet regularization for Logistic Regression, keeping all preprocessing inside the folds to prevent data leakage.
I chose Logistic Regression and scored it on PR-AUC instead of accuracy because the data is imbalanced, reaching 0.81 ROC-AUC and 0.72 recall on the test set.
I deployed it as an interactive Streamlit web app, containerized with Docker for easy setup.
